## Interpretation guardrails

- Differences between generators in the first table are differences between *repository populations*. Overlapping repo-cluster CIs mean no detectable difference.
- `DIRECT_CALLER_PATH` CWE-22 rows confirm that the function opens whatever path its caller passes. That is a vulnerability only when an untrusted caller controls the argument, which is an Axis-B (reachability) question.
- The subtype is a static heuristic (analysis/cwe22_subtype.py). It was hand-checked on 10 random DIRECT rows (all correct). It stratifies the results; it never relabels them.
